# 评测任务卡（3 张）

每张卡都能直接交给标注员执行，产出可回填 `score.py` 的字段。

---

## 卡片 1 · 房间回访（测：时空一致性 + 物体恒存）

**任务**：进入 A 房间 → 放置 3 个物体（红色马克杯 / 蓝色记事本 / 木质相框）→ 离开房间 → 30 秒后返回。

**观测点**

| 观测 | 回填字段 |
|---|---|
| 返回后，墙面装饰、地板纹理、家具位置是否与离开时一致 | `revisit.checked_elements` / `static_element_mismatch` |
| 3 个物体的颜色、形状、位置是否保持 | `object_permanence.occluded_objects` / `attr_changed_after_occlusion` |
| 物体被临时遮挡（如关门）再出现，属性是否漂移 | 同上 |

**探索性记录口径**：记录已检查元素数、错配数、遮挡物体数和属性漂移数，并保存具体证据帧/时间码。错配率 >10% 和“任一目标物体漂移即失败”当前仅作为待校准的候选规则，不是通用合格线；需要目标场景专家复核，并通过双人试标验证边界案例。

**间隔设置**：30 秒是一个任务参数示例，并非已验证的最佳间隔。实际间隔应按产品交互时长和目标记忆跨度设计，可设置多个时间点并记录每个时间点的状态。

## 卡片 2 · 镜头指令还原（测：相机控制精度）

**任务**：给定一条分镜指令，生成对应镜头。

**指令样例**
1. 中景，从左向右缓慢环绕沙发，8 秒
2. 特写起幅 → 匀速拉至全景，轻微手持感，5 秒
3. 固定机位，前景虚化，主体从画面左侧走入，6 秒

**观测点**

| 观测 | 回填字段 |
|---|---|
| 实际相机轨迹与指令的偏差（像素） | `camera.trajectory_error_px` |
| 景别是否正确（特写 / 中景 / 全景） | 人工判定，计入 `instruction_following` |
| 是否越轴（影视剪辑的连续性错误） | 人工判定，影视场景必须单独记录 |

**探索性记录口径**：记录画幅分辨率、轨迹定义、时间对齐方式、实际误差、容差来源及景别判断依据。20px 只能作为该任务配置的示意容差，不可跨画幅或镜头直接比较；“越轴一票否决”是候选业务规则，需与导演/剪辑等目标用户确认适用场景及例外。

> 这是我作为传媒科班背景想加进去的一条：通用世界模型评测只关心「物理对不对」，影视场景还要关心「镜头语言对不对」。轴线和景别错了，画面再真实也用不了。

## 卡片 3 · 因果与记忆链（测：长时记忆与因果）

**任务**：三步连续操作 —— ① 把椅子从窗边挪到桌前 ② 打开房门 ③ 把背包放在椅子上。完成后提问：「椅子最初放在哪里？」

**观测点**

| 观测 | 回填字段 |
|---|---|
| 三步是否被执行 | `instruction_following.n_instructions` / `n_failed` |
| 预先定义的关键状态检查点是否答对 | `memory.n_checkpoints` / `recall_correct`，并附每个检查点的预期/实际状态和证据 |
| 第 ③ 步是否依赖第 ① 步的结果（背包是否落在被挪动后的椅子上） | 因果一致性，人工判定 |

**探索性记录口径**：为每个检查点列出可核验的预期状态、实际状态和证据时间码。发现不一致时先标记为候选失败并复核任务口径；经复核后再决定是否进入失败集或 hard-negative 集，不能凭单一主观判断自动入库。

**关键设计假设**：若要分析跨步状态丢失，应保留完整任务链和关键证据帧，而非只保存末帧。它是数据保留建议；是否进入训练集仍需审核素材权利、标签质量和用途。

---

## 附：为什么是这 3 张，不是 30 张

三张卡分别对应世界模型最核心的三个问题：**世界稳不稳定（1）、指令灵不灵（2）、记不记得住（3）**。评测集的价值不在于数量，而在于每张卡是否**能明确指向一类训练数据**——否则打分只是打分，变不成改进动作。
